## Unsupported In 0.1.0

- `mtmd` multimodal API;
- CUDA, Vulkan, RPC, and other upstream backends;
- C++17 consumer compatibility;
- a claim that every upstream model architecture works.

Deprecated upstream C APIs are exported and can produce upstream deprecation
warnings when called. A new model or backend support claim requires its own
targeted runtime evidence.
